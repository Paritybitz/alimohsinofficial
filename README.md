# Ali Mohsin — personal site

A single-page digital business card: name, one line, four chapters
(Career, Projects, Content, Photography) that open as quiet overlays.

React + TypeScript + Vite. No UI libraries, no animation libraries.

## Run locally

```bash
npm install
npm run dev        # http://localhost:5173
```

Other commands:

```bash
npm run build      # type-check + production build → dist/
npm run preview    # serve the production build
npm run lint       # oxlint
```

## Where to edit your content

Everything personal is in **`src/data/portfolio.ts`**:

- `socialLinks`: LinkedIn, GitHub, Instagram and email (an empty `href` renders as plain text, never a dead or wrong link)
- `sections.career`: intro, roles, up to three highlights
- `sections.projects`: two or three projects with tags and links
- `sections.content`: creative statement and up to three pieces (thumbnails optional)
- `sections.photography`: three to five photos

Anything with `placeholder: true` shows a small "placeholder" tag in the
overlay. Delete the flag when you replace the text.

**Photos:** put files in `public/images/photography/` and set
`src: '/images/photography/your-file.jpg'` plus the real `ratio`
(width ÷ height). Export at about 2000px on the long edge, as JPEG or WebP
around 80% quality. Thumbnails for Content go in `public/images/content/`.

## Name, logo and fonts

- **Name:** "ALI MOHSIN." in Bruno Ace (SIL Open Font License), converted to
  a vector path so it can take the brushed-metal fill. Generated by
  `scripts/build-name-mark.mjs` from `scripts/fonts/BrunoAce-Regular.woff`;
  run `npm run name-mark` after changing the wording or spacing there.
- **Logo:** `public/images/logo-am.png`, cleaned from your AM monogram.
- **Text:** D-DIN by Datto (the typeface SpaceX uses on its website), SIL
  Open Font License, bundled from `src/assets/fonts/`.
- **Icons:** outline icons adapted from Lucide (ISC licence).
- **Colours:** no pure white. Tokens are at the top of `src/styles/globals.css`.

## Background

- A slow drift through a starfield, drawn on a canvas (`src/lib/space.ts`).
- Faint sunlight from a sun far off-screen to the left, about 30% up from
  the bottom (`.ambient__sun` in `globals.css`).
- Optional video: set `backgroundClip.src` in `src/data/portfolio.ts` to an
  .mp4 in `public/videos/`. It plays faintly, toned to the palette.
- Visitors who turn on "reduce motion" get a still frame with no video.

## Email

The email icon opens a Gmail draft addressed to you. To use the visitor's
default mail app instead, set `emailOpensIn = 'mail-app'` in
`src/data/portfolio.ts`.

## Structure

```
src/
  data/portfolio.ts          ← all content and links
  components/
    LandingPage.tsx          page shell + open/close state
    IdentityHero.tsx         name (SVG) + subtitle
    CategoryNavigation.tsx   the four chapters
    SocialLinks.tsx          bottom icon links
    SocialIcons.tsx          LinkedIn / GitHub / Instagram / email icons
    BrandMark.tsx            AM logo, top left
    AmbientBackground.tsx    stars, sunlight, optional video
    SectionOverlay.tsx       chapter overlay
    Dialog.tsx               shared accessible <dialog>
    PhotoViewer.tsx          single-photo view
    sections/                one component per chapter
  styles/
    fonts.css                font files ↔ family names
  assets/fonts/              D-DIN (OFL) and licence
  data/nameMark.ts           your name as a vector path (generated)
  lib/space.ts               starfield animation
scripts/build-name-mark.mjs  draws the name from Bruno Ace
    globals.css              tokens, layout, motion
```
